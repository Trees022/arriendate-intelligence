# Arriendate Intelligence

Production-minded Applied AI system for real-estate lead and property matching.

Natural-language lead
        ↓
Structured extraction
        ↓
Deterministic hard constraints
        ↓
Eligible properties
        ↓
Embeddings + pgvector
        ↓
Semantic ranking
        ↓
Grounded Top-N matches
        ↓
Human review

## Stack

Python · FastAPI · PostgreSQL · Supabase · pgvector
React · TypeScript · Docker · Pytest · Playwright · CI

## Why I built it

Real-estate leads arrive as unstructured conversations.
Arriendate Intelligence converts those conversations into validated,
traceable requirements and matches them against properties while keeping
eligibility rules deterministic and AI decisions constrained.
